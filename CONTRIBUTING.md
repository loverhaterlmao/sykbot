# Helping with Sykbot

Sykbot's source is closed, so there is no code to send a pull request against. The help that moves it forward is
the kind only people using it can give.

## Report what broke

Open an issue with:

1. **What you did**: the exact request or steps.
2. **What you expected.**
3. **What happened instead**: the message you saw, a screenshot if it helps.
4. **Whether it happens every time.**

One problem per issue. Never include passwords, keys or personal details.

## Suggest something

Say what you are trying to get done, not only the feature you imagine. "I need to hand a build to a client without
an account" tells us more than "add sharing".

## Test with us

We invite people who report well to try things early. If you would like that, say so in an issue or at
support@snns.dev.

## What we ask

Be specific, be kind, and follow the [code of conduct](CODE_OF_CONDUCT.md). Anything you send us we may use to
improve the product, without obligation to you.

Fixes to these documents are welcome as pull requests.
